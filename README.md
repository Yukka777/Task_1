# Дипломный проект: Система заказа бургеров

Проект представляет собой систему для создания и управления заказами бургеров.

## Структура проекта

- `praktikum/` - исходный код приложения
- `tests/` - модульные тесты
- `requirements.txt` - зависимости

## Запуск тестов

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск тестов с покрытием
python -m pytest tests/ -v --cov=praktikum

# Генерация HTML отчета
python -m pytest tests/ --cov=praktikum --cov-report=html
Тестовое покрытие
✅ 100% покрытие кода достигнуто для всех модулей.
